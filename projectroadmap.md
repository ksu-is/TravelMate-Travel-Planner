# TravelMate – Project Roadmap

## Project Overview
TravelMate is a Python-based travel planning and budgeting assistant designed to help users organize their trips in one place. Users will be able to explore hotels, restaurants, attractions, and pet hotels, estimate travel expenses, and save their trip information to return to later.

The long-term goal is to develop TravelMate into a website that combines travel planning, organization, and budgeting.
